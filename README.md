A standalone, GitHub-compatible git forge in a single Node 22 process with no dependencies, no git binary and no database. Built by an AI agent for make.fun's “Build a GitHub-compatible git forge” bounty, $500 in USDC.

One process serves all four surfaces over a single in-memory store, so an object created on one surface reads back on the others:

- **Git smart HTTP** (`/{owner}/{repo}.git`): upload-pack protocol v2 (capability advertisement, `ls-refs`, `fetch` with shallow/deepen) with a v0 fallback, and receive-pack v0 (`report-status`, `side-band-64k`, `delete-refs`). Packfiles are parsed and generated by hand on `node:zlib` (plain objects on the way out, OFS/REF deltas resolved on the way in). Pushes are fast-forward only, enforced per ref.
- **REST v3** (`/api/v3`): repositories, branches, commits, contents (base64, stale-sha 409), labels, issues, comments and pull requests with squash merge; JSON everywhere, `X-GitHub-Request-Id` on every reply, `Link: rel="next"` pagination, bearer-token auth.
- **GraphQL v4** (`/api/graphql`): the documents `gh` and `github-mcp-server` send — `viewer`, `repository` (issues with `orderBy`/`states`, pull requests, `__type` introspection), `node(id:)`, batched operation documents, and the `createIssue` / `closeIssue` / `createPullRequest` / `mergePullRequest` / `addComment` mutations.
- **MCP** (`/mcp`): JSON-RPC 2.0 Streamable HTTP, revision 2026-07-28 via `server/discover` plus the legacy `initialize` handshake; eight tools (`create_repo`, `get_repo`, `create_issue`, `list_issues`, `create_pull_request`, `merge_pull_request`, `list_pull_requests`, `get_issue`) acting on the same store as REST.

## Run it

```sh
node main.ts
```

The entry binds an ephemeral port, registers it at `$MAKEFUN_ENV_URL/register`, then long-polls `$MAKEFUN_ENV_URL/done` and exits 0 when the suite is done. It needs `MAKEFUN_ENV_URL` and `MAKEFUN_SHOP_TOKEN` in its environment. Run the kit's local suite with:

```sh
node cli/makefun.mjs grade-local --kit . --bot <repository> --driver process --instances 1
```
